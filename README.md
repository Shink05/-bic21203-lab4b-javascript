## Setup
1. Open the folder in VS Code and install the **Live Server** extension (or run `python3 -m http.server 8000` in the folder).
2. Start the server and open `books.html` through `http://localhost/...`. Do **not** open it with `file://`, because `fetch()` will fail.
3. `jquery-dom.html` needs an internet connection to load jQuery from `https://code.jquery.com/jquery-4.0.0.min.js`.
